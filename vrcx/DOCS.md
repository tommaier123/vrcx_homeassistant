# VRCX

Runs the official Linux build of [VRCX](https://github.com/vrcx-team/VRCX) in a Home Assistant sidebar tab.

- The first start downloads the latest VRCX release (about 180 MB).
- VRCX's built-in updater installs new versions automatically. Keep **Auto Update** set to **Auto Download** in VRCX's settings.
- Login and history are stored in the add-on's config folder, so they survive restarts and are included in backups.
